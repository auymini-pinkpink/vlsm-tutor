📖 Learn Subnetting & VLSM

1. What is VLSM?

Variable Length Subnet Masking (VLSM) allows network engineers to divide an IP address space into subnets of different sizes, reducing IP address waste.

2. Key Rules for VLSM:

  • Always allocate subnets starting with the largest required host count down to the smallest.
  • Formula for total IP block size needed: Block Size = 2Host Bits where Host Bits can fit Needed Hosts + 2 (1 for Network ID, 1 for Broadcast ID).
  • CIDR Prefix Formula: /CIDR = 32 - Host Bits.
