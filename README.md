# 🖧 VLSM Tutor & Subnetting Master Studio

A lightweight, standalone web application designed for network engineers and students to calculate Variable Length Subnet Masks (VLSM) efficiently and practice subnetting concepts.

![VLSM Tutor Studio](https://via.placeholder.com/800x400?text=VLSM+Tutor+Studio)

---

## ✨ Features

- **VLSM Calculation Engine:** Automatically sorts subnets by size and calculates prefix lengths, network addresses, usable IP ranges, and broadcast addresses.
- **Space Allocation Metrics:** Displays live capacity usage, total network capacity, and unassigned IP counts.
- **Dynamic Subnet Builder:** Add or remove subnets dynamically according to specific host requirements.
- **Green Accent Theme:** Clear green status highlighting for calculated results and allocated ranges.
- **Responsive & Lightweight:** Pure standard HTML5, CSS3, and modern JavaScript—no heavy frameworks or external dependencies required.
